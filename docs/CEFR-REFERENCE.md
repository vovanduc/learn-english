# CEFR reference

The course uses CEFR A1/A2 descriptors as a target framework, not as an official certification.

The lesson design emphasizes practical listening and spoken interaction evidence. A learner is considered to have useful progress when they can perform the relevant Can-Do task in a live interaction, not merely complete grammar exercises.

# Lesson package

A completed lesson folder contains:

- `README.md` — learner-facing overview
- `SOURCE.md` — source exercise content and metadata
- `PRE-CLASS.md` — 5–10 minute listening preparation
- `PROMPT.md` — prompt to paste into a fresh ChatGPT Voice session
- `ANSWER-KEY.md` — teacher-only answers
- `TRANSCRIPT.md` — teacher-only transcript
- `SESSION-REPORT.md` — report template/output target

Teacher-only data must not be revealed before the learner attempts the matching source task.

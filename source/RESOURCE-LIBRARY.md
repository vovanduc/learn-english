# Resource Library

## Google Drive — source library

Use this Google Drive folder as the long-term source library when generating future lessons or levels:

https://drive.google.com/drive/folders/1REXkQUPJUBAxhnNEd9XkTg4eOIz0e_Zf

### Expected use

- Primary reference library for additional course materials supplied by the learner.
- Check this location when a requested lesson or level needs source material not already present in the GitHub repository.
- Preserve the source material's original level, ordering, terminology, exercises, transcripts, answer keys, and links.
- Do not silently replace source content with unrelated material.
- When multiple sources exist, identify which file/material was used for the lesson.

### Future levels

The library may contain materials for higher levels, including:

- A1
- A2
- B1
- B2
- C1
- C2

The current course implementation focuses on A1 → A2. B and C levels are future expansion tracks and should be added only from source materials actually available in the library/repository.

### Source hierarchy

1. Lesson-specific source files in this repository
2. Original materials in the Google Drive source library
3. Explicitly approved supplementary external resources

External resources are supplementary and must not silently replace the primary course source.

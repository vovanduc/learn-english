# A1-02 — At the library: giving personal information

## Objective
Primary focus: listening comprehension + spoken transfer at A1.

## Source
- British Council source: https://learnenglishteens.britishcouncil.org/skills/listening/a1-listening/library-giving-personal-information
- Audio: https://learnenglishteens.britishcouncil.org/sites/teens/files/2024-08/A1_at_the_library.mp3

## Core language
First name, surname, spelling, age, class, photo, simple personal information.

## Session design
- Pre-class: 5–10 minutes
- Voice session: 25–30 minutes
- Post-class: session report + short speaking homework

## Important
The learner must attempt the listening tasks before seeing the transcript or answer key.

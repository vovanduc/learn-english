# A1-03 — Band auditions

## Objective
Primary focus: listening comprehension + spoken transfer at A1.

## Source
- British Council: https://learnenglishteens.britishcouncil.org/skills/listening/a1-listening/band-auditions
- Audio: https://learnenglishteens.britishcouncil.org/sites/teens/files/2024-08/A1_band_audition.mp3

## Core language
band, instrument, audition, singer, guitarist, drummer, can/can't, good, try.

## Session design
- Pre-class: 5–10 minutes
- Voice session: 25–30 minutes
- Post-class: session report + speaking homework

## Important
The learner must attempt listening tasks before seeing the answer key or transcript.
